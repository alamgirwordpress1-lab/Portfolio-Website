# Md Alamgir Hossen — Portfolio

Personal portfolio for **Md Alamgir Hossen**, Senior WordPress & Next.js Developer.
Built with **Next.js 16 (App Router, Turbopack) + Tailwind CSS v4 + GSAP (ScrollTrigger, SplitText) + Lenis smooth scroll**. Package manager: **pnpm**.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000

## Production build

```bash
pnpm build
pnpm start
```

The site is fully static (prerendered), so it can also be deployed to Vercel, Netlify or any Node host with zero config.

## Where to edit content

All text content lives in one file: **`lib/data.ts`**

- `site` — name, role, tagline, email, phone, links, availability badge
- `stats` — hero counter numbers
- `services` — the 8 service cards
- `skillGroups` — skill matrix chips
- `headlessFlow` / `modernStacks` — the "How I build for the modern web" section
- `signatureBuilds` — the 4 case-study cards
- `projects` — live project cards (screenshots auto-generate from each URL via WordPress mshots)
- `experience` / `education` — timeline and education cards
- `journey` — the year-by-year mini timeline in About
- `marqueeTech` — scrolling tech ticker items

SEO metadata is in `app/layout.tsx`. Colors/fonts are design tokens in `app/globals.css` (`@theme` block).

## Structure

```
app/            layout (fonts + metadata), page, global styles, favicon
components/     one component per section + shared (Preloader, Header, MagneticButton…)
lib/            data.ts (all content), gsapSetup.ts, icons.ts (simple-icons subset)
```

## Notes

- Project screenshots are generated by `https://s0.wp.com/mshots/v1/…` on first request — the first
  load may show a placeholder for a few seconds until WordPress.com caches the screenshot.
- GSAP SplitText/ScrollTrigger are the official plugins (free since GSAP 3.13).
